# Practice

## Purpose
Scratch folder for small, one-off Python exercises — not a reusable library,
so it skips the package/`operations`-style structure the other projects use.

## Structure
- `add_two_numbers.py` — standalone script, prompts for two numbers and
  prints their sum.

## How to run

```
D:\Software\Python_venv\venv_1\Scripts\python.exe add_two_numbers.py
```
